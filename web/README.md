# Matchmaker Web

Фронтенд MVP Matchmaker на React + TypeScript + Vite.

## Запуск

```bash
npm install
npm run dev
```

## Сборка и тесты

```bash
npm run build
npm run test
npm run test:watch
npm run coverage
```

## Что уже есть

- Vite-проект с React Router.
- Публичные страницы `/`, `/login`, `/register`.
- Защищённые маршруты-заглушки `/feed`, `/projects`, `/profile`, `/matches`, `/chat/:matchId`.
- Публичный `404`.
- Базовая структура для последующих фаз auth и protected layout.
